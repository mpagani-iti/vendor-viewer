# Vendor Viewer

Vendor Viewer is a lightweight dashboard for browsing a company’s vendor directory. It provides quick filtering, at-a-glance status indicators, and location details so operations teams can find and review vendor records.

Built with Vue, TypeScript, Vite, and Tailwind CSS.

## Run locally

```
npm install
npm run dev
```

## Other commands

```sh
npm run build
npm test
npm run lint
```
